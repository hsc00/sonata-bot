# Introduction

**Sonata** is a Discord bot that allows you to retrieve album information and import ratings from [RateYourMusic](https://rateyourmusic.com/). 

## 📋 Features

- Retrieve information about music releases.
- Check user profiles and statistics.
- Explore ratings within your Discord server.

## 🚀 Getting Started

Start by importing your ratings from [RateYourMusic](https://rateyourmusic.com/) by using the [`!import_ratings`](commands/users.md#import_ratings-i) command.  
If you have [Last.fm](https://www.last.fm/), link your account using the [`!set_lastfm`](commands/users.md#set_lastfm) command to automatically use the release you're currently listening to in other commands.  
After that, you can then use the various commands to explore yours and the server members' ratings as well as information about specific releases.
